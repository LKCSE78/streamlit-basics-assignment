## 🚀 Overview

A simple and interactive **Streamlit dashboard** built to present sales data in a user-friendly way.
This app allows non-technical users to **filter sales data by category** and visualize trends instantly.

---

## ✨ Features

* 📌 Interactive UI built with Streamlit
* 📂 Hardcoded dataset using Pandas
* 🔍 Sidebar filter for category selection
* 📊 Dynamic table display
* 📈 Line chart visualization of sales

---

## 🛠️ Tech Stack

* **Python**
* **Pandas**
* **Streamlit**

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/sales-dashboard.git
cd sales-dashboard
```

### 2. Install Dependencies

```bash
pip install streamlit pandas
```

### 3. Run the App

```bash
streamlit run sales_app.py
```

---

## 📊 How It Works

* A predefined dataset is loaded into a Pandas DataFrame
* Users select a **category from the sidebar**
* The app filters and displays relevant data
* A **line chart updates dynamically** based on selection

---

* Share data interactively instead of static reports
